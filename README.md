# Toyota_Stock_Prediction
Este proyecto se enfoca en la predicción de los precios de cierre de las acciones de Toyota utilizando un modelo de regresión lineal. El conjunto de datos incluye información histórica sobre el precio de apertura, el precio más alto, el precio más bajo y el volumen de acciones negociadas. A través del análisis de estos datos, se desarrolló un modelo predictivo para estimar el precio de cierre de las acciones en base a las variables proporcionadas.

Objetivos:

Predecir el precio de cierre de las acciones de Toyota utilizando datos históricos.
Evaluar el rendimiento del modelo con métricas como MSE (Error Cuadrático Medio) y R² (Coeficiente de Determinación).
Aprender y aplicar técnicas de regresión lineal en problemas de predicción de series temporales.
Próximos pasos:

Mejorar el modelo utilizando otros algoritmos o técnicas de optimización.
Evaluar el modelo con nuevos datos para verificar su capacidad de generalización.
